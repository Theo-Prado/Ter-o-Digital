# 📿 Terço Digital

> Um terço digital interativo para ajudar a rezar o terço sem precisar de um terço físico.

---

## ✝️ Sobre o Projeto

O **Terço Digital** é uma aplicação de linha de comando desenvolvida em Python que guia o usuário passo a passo na reza do terço católico. O programa exibe cada oração na sequência correta e registra a contagem automaticamente, eliminando a necessidade de um terço físico.

---

## ⚙️ Funcionalidades

- Saudação personalizada com o nome do usuário
- Guia completo das **orações iniciais** (Em Nome do Pai, Credo, Pai Nosso, Ave Marias, Glória e Oh Meu Jesus)
- Guia dos **5 mistérios** com todas as orações de cada dezena (Ave Marias, Glória, Oh Meu Jesus e Pai Nosso)
- Contagem automática das orações rezadas
- Encerramento com a oração da **Salve Rainha**
- Mensagem de conclusão personalizada ao final do terço

---

## 🚀 Como Usar

### Pré-requisitos

- Python 3.x instalado

### Executando o programa

```bash
python terco_digital.py
```

### Passo a passo

1. Execute o programa
2. Digite seu nome quando solicitado
3. Para cada oração exibida na tela, reze-a e depois **digite `1`** para avançar para a próxima
4. Siga o guia até a conclusão do terço com a Salve Rainha

---

## 📖 Estrutura das Orações

### Orações Iniciais
| Oração | Quantidade |
|---|---|
| Em Nome do Pai | 1 |
| Credo | 1 |
| Pai Nosso | 1 |
| Ave Maria | 3 |
| Glória | 1 |
| Oh Meu Jesus | 1 |

### Cada Mistério (repetido 5 vezes)
| Oração | Quantidade |
|---|---|
| Mistério | 1 |
| Pai Nosso | 1 |
| Ave Maria | 10 |
| Glória | 1 |
| Oh Meu Jesus | 1 |
